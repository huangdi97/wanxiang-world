# ADR-0043: Synthetic Mansion Living-world Qualification Design (G08A)
- Status: accepted
- Date: 2026-08-13

## Context
G08A needs a synthetic mansion Domain/World/Scenario proving seven-day
persistence/control/knowledge/material/branch behavior without Core hacks.

## Decision
1. The mansion package is authored and run through existing authoritative
   paths (scheduler/lifecycle/session/lease/handoff/material/epistemic/branch).
2. Domain rules are plugins/packages above Core.

## Consequences
- The mansion is evidence that unrelated domains run on the same core.
