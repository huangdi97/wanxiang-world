# Synthetic Mansion Living-world Qualification (G08A)

`tests/integration/test_m7_mansion.py` authors a synthetic mansion
Domain/World/Scenario through the authoritative pipeline and runs seven
in-world days with no-user periods, human takeover/resume (session + lease +
handoff), a day-3 alternate branch (fork never mutates parent), and letter
custody/read/knowledge propagation through material + epistemic paths. No Core
hacks; domain rules live as plugins/packages above Core.
