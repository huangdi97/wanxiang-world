# Gymnasium / PettingZoo Research Adapters (G12D)

`wanxiang_substrate.research` provides Gymnasium-style single-agent
(`CampaignGymAdapter`) and PettingZoo-style multi-agent
(`CampaignPettingZooAdapter`) adapters with reset/step/seed, observation/action
spaces, and epistemic filtering (fog-of-war). Optional dependencies are not
required; authority is preserved (actions become proposed orders).
