# Opportunity / Challenge / Event Compiler (G07C)
Ownership: `wanxiang_substrate.reality.challenge`.

## Opportunity
`Opportunity` is a detected world condition with kind/score/time.
`DefaultOpportunityDetector` is a deterministic domain-neutral port.

## ChallengeSpec
`ChallengeSpec` carries executable prerequisites, safety/rights/evidence
requirements and verifiable end conditions, compiled by `ChallengeCompiler`.
