# 用户需要做什么

本轮默认可以尽量全自动执行。

## 通常不需要用户提供

- 新的真实书；
- GEDCOM；
- 训练数据；
- 自训练模型；
- 新 GitHub 仓库。

v5.4 已经有真实 Source-created worlds，可以直接作为 v5.5 long-horizon / playable / lab 的验收对象。

## 只有以下情况需要用户介入

1. GitHub/远端再次要求授权；
2. 你明确希望验证某个外部 Godot/Unreal/SimWorld/在线模型 Provider，而环境需要安装或凭证；
3. 需要决定公开世界/UGC 的产品政策或法律条款；
4. 某个真实 Source rights 需要新的用户授权。

否则 Codex 应自动完成到 M94。
